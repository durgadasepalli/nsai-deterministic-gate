# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, assume good intent, give constructive feedback, and do not harass anyone. The full text at the link above applies to all project spaces — issues, pull requests, discussions — and to anyone representing the project in public.

## Reporting

If you experience or witness unacceptable behaviour, email the maintainer, Durga Prasad Dasepalli, at [ddasepalli@gmail.com](mailto:ddasepalli@gmail.com). Reports are handled confidentially.

The maintainer will review each report and may take any action they consider appropriate, from a private warning to a permanent ban from project spaces, following the Contributor Covenant's enforcement guidelines.
